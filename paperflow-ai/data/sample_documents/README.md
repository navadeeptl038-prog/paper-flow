# Sample documents

Place non-sensitive demo files here for local development and hackathon demos.

Supported formats (when processing is implemented):

- PDF
- DOCX
- JPG / JPEG
- PNG
- WEBP
- HEIC / HEIF

Do not store real personal documents, passports, IDs, or secrets in this folder.

Original production documents belong in private Supabase Storage, not on the Render filesystem.
